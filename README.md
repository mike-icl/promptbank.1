# SAT Prompt Bank — 2026 Digital SAT

Live site: **https://mike-icl.github.io/promptbank.1/**

22 copy-paste prompts that generate full Digital SAT lessons
(Concept + Strategy + Worked Example + 3 Practice Qs + Answer Key).

## 2026 Digital SAT specs (baked into every prompt)
- 98 Qs total | RW: 2 x 27 Qs, 32 min each | Math: 2 x 22 Qs, 35 min each
- ~2h14m + 10-min break | Multistage adaptive Module 2
- RW = PAIRED passages (~400–600 words total), ONE question per passage
- Math = Desmos on EVERY question, all multiple choice (no grid-ins), no no-calculator section
- Essay discontinued — not tested | No penalty for guessing

## Use
Open `index.html` (or the live URL), filter by section, click **Copy Prompt**,
paste into ChatGPT / Claude / Gemini.
